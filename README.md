# 휴양림 발매 키오스크

산림청통합운영관리 사이트의 발매(입장권 구매) 페이지를 터치 키오스크용으로
단순화해서 보여주는 도구입니다. 사이트 자체를 수정하거나 로그인/결제 로직을
우회하지 않고, **Chrome 확장프로그램이 실제 페이지 위에 전체화면 오버레이를
얹어서** 손님에게는 "발매유형 선택 → 수량 선택 → 신용카드 결제" 버튼만
보이게 합니다. 오버레이에서의 조작은 실제 페이지의 해당 요소(라디오/셀렉트,
수량 입력창, 결제 버튼)에 그대로 값 변경/클릭 이벤트를 전달하므로, 로그인
세션과 카드결제기 연동 등 기존 사이트 동작은 전혀 바뀌지 않습니다.

## 동작 원리

1. 직원이 아침에 키오스크 PC를 켜면 Chrome이 키오스크 모드(`--kiosk`)로
   실행되며 로그인 페이지가 뜹니다.
2. 직원이 공인인증서로 평소처럼 수동 로그인합니다. (자동 로그인은 구현하지
   않았습니다 — 인증서 비밀번호를 코드에 저장하지 않기 위함)
3. 로그인 후 발매 페이지로 이동하면, 확장프로그램의 content script가 해당
   URL 패턴(`config.js`의 `activatePathPattern`)을 감지하고 실제 화면 위에
   전체화면 오버레이 UI를 띄웁니다.
4. 손님은 오버레이의 큰 버튼으로만 유형/수량을 고르고 "신용카드 결제"를
   누릅니다. 이 클릭은 실제 페이지의 결제 버튼 클릭으로 그대로 전달되어,
   기존에 연결되어 있던 카드결제기 결제 흐름이 동일하게 진행됩니다.
5. 관리자가 화면 좌상단 모서리를 짧은 시간 안에 5번 터치하면 비밀번호
   입력창이 뜨고, 맞으면 오버레이가 사라져 실제 화면(로그아웃, 오류 확인,
   재로그인 등)을 다시 조작할 수 있습니다.

## ⚠️ 지금 바로 채워야 하는 부분

실제 발매 페이지의 HTML 구조를 모르는 상태로 만든 뼈대(scaffold)입니다.
아래 파일에서 `TODO` 로 표시된 값을 실제 값으로 바꿔야 동작합니다.

- `extension/manifest.json`
  - `host_permissions`, `content_scripts.matches`의 `REPLACE_WITH_REAL_DOMAIN`
- `extension/config.js`
  - `activatePathPattern` — 발매 페이지 URL을 구분하는 정규식
  - `selectors.ticketTypeContainer` / `ticketTypeOptionSelector` — 발매유형
    선택 영역
  - `selectors.quantityInput` — 수량 입력창
  - `selectors.payButton` — "신용카드" 결제 버튼
  - `selectors.quantityMin` / `quantityMax` — 실제 페이지와 동일하게
  - `staffExit.password` — 운영 전 반드시 변경
- `scripts/launch-kiosk.sh` / `launch-kiosk.bat`
  - `START_URL` — 로그인 페이지 실제 주소

선택자를 뽑는 가장 쉬운 방법: 실제 발매 페이지에서 해당 요소를 우클릭 →
"검사(Inspect)" → Elements 패널에서 요소 우클릭 → Copy → **Copy selector**.

## 선택자 채운 뒤 테스트하는 법

1. `chrome://extensions` 접속 → 우측 상단 "개발자 모드" 켜기
2. "압축해제된 확장 프로그램을 로드합니다" 클릭 → 이 저장소의 `extension`
   폴더 선택
3. 일반 Chrome 창(키오스크 모드 아님)으로 실제 사이트에 로그인 후 발매
   페이지로 이동해 오버레이가 정상적으로 뜨는지, 유형/수량/결제 버튼이
   실제 페이지에 잘 반영되는지 확인
4. 정상 동작 확인 후 `scripts/launch-kiosk.sh`(리눅스) 또는
   `launch-kiosk.bat`(윈도우)로 키오스크 모드 실행

## 운영 시 참고 사항

- **자동 시작**: 리눅스는 `systemd` 유저 서비스나 데스크톱 자동실행 항목에,
  윈도우는 시작프로그램 폴더나 작업 스케줄러에 launch 스크립트를 등록하면
  재부팅 시 자동으로 키오스크가 뜨게 할 수 있습니다.
- **개발자 모드 확장 경고**: 최신 Chrome은 `--load-extension`으로 로드한
  확장에 대해 가끔 "개발자 모드 확장 프로그램" 경고 배너를 띄울 수
  있습니다. 완전히 배너 없는 운영이 필요하면 확장을 `.crx`로 패키징하고
  Chrome 기업 정책(`ExtensionInstallForcelist`)으로 설치하는 방식을
  고려하세요.
- **키오스크 탈출 방지**: `--kiosk` 플래그만으로는 일부 키보드 단축키(Alt+F4,
  Ctrl+N 등)를 막지 못할 수 있습니다. 실제 무인 배치 전에 터치 전용 환경에서
  키보드/마우스 없이도 문제가 없는지 확인하고, 필요하면 OS 레벨 키오스크
  잠금(예: 우분투 kiosk 세션, 윈도우 Assigned Access)을 함께 적용하세요.
- **보안 범위**: 이 확장은 화면에 보이는 UI만 재구성할 뿐, 로그인 인증이나
  결제 처리 로직 자체는 전혀 건드리지 않습니다. 카드 정보는 여전히 사이트와
  카드결제기 사이의 기존 흐름으로만 오갑니다.
