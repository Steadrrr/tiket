# 데스크톱 동반자 (Desktop Companion)

바탕화면에 VRM 3D 캐릭터를 띄우고, Claude API와 대화하는 개인 AI 비서입니다. (Windows 기준, 1단계 MVP)

```
Electron 투명 창 + three-vrm 캐릭터
  ├─ 대화: Claude (기본 Haiku 5.5, 설정에서 Sonnet/Opus 로 변경)
  ├─ 기억: 로컬 SQLite (대화 기록 · 장기 기억 · 롤링 요약) + 자동 백업
  ├─ 음성 출력: TTS 교체형 (지금은 Edge TTS, Style-Bert-VITS2 연결부 포함)
  └─ 도구: 기억 저장 / (선택) 브라우저·앱 열기 / (선택) 화면 보기
```

## 설치와 실행 (집 Windows PC)

> ⚠ **업무용/행정망 PC에는 설치하지 마세요.** 허가되지 않은 프로그램 설치와, 업무 내용이 외부 AI API로 전송되는 것은 보안 규정 위반이 될 수 있습니다. 개인 PC에서만 사용하세요.

1. [Node.js](https://nodejs.org) **22 LTS 이상** 설치
2. 터미널에서:
   ```bash
   cd companion
   npm install
   npm start        # 빌드 후 실행
   ```
   개발 중에는 `npm run dev` (화면 코드 수정이 바로 반영됩니다).
3. 캐릭터 아래 **⚙ 설정**에서 [Anthropic API 키](https://console.anthropic.com/)를 입력합니다. 키는 Windows 보안 저장소(DPAPI)로 암호화되어 저장되며, 환경변수 `ANTHROPIC_API_KEY`로도 줄 수 있습니다.
4. 아바타를 구하면 설정 → **VRM 파일 선택**. 선택하지 않으면 기본 캐릭터(분홍 인형)가 나옵니다.

네이티브 모듈이 없어서(SQLite는 Node 내장 `node:sqlite` 사용) Visual Studio Build Tools 같은 것은 필요 없습니다.

## 사용법

| 동작 | 방법 |
|---|---|
| 대화 | 아래 입력창에 입력 후 Enter |
| 답변 중단 | ■ 버튼 또는 Esc |
| 캐릭터 이동 | 캐릭터를 드래그 |
| 창 숨기기/보이기, 설정, 종료 | 작업 표시줄 트레이 아이콘 |
| 클릭 통과 | 설정(또는 트레이)에서 켜면 캐릭터·UI 이외 영역은 뒤의 창을 클릭할 수 있음 |
| 표시 모니터 | 설정 → 표시할 모니터 (듀얼 모니터 지원) |

캐릭터의 눈은 데스크톱 어디에 있든 마우스 커서를 따라갑니다.

## 아바타 (부스 구매 시)

- **VRM 파일로 제공되는 상품**이면 그대로 선택하면 됩니다. (VRM 0.x, 1.0 모두 지원)
- VRChat용 FBX / Unity 패키지만 있는 경우 Unity + UniVRM 으로 VRM 변환이 필요합니다.
- 라이선스에서 "개인 사용", "改変(개변)", "프로그램 탑재" 조건을 확인하세요. 개인 PC에서만 쓰는 용도와 배포는 조건이 다릅니다.
- 표정(기쁨/화남/슬픔/놀람/편안), 눈 깜빡임, 립싱크(`aa`)는 VRM 표준 BlendShape 를 씁니다. 해당 표정이 없는 모델은 일부 표정이 안 보일 수 있습니다.

## 모델 변경 (Haiku → Sonnet)

설정 → 모델에서 바꾸면 됩니다. **기억은 모델과 무관하게 앱의 로컬 DB에 있으므로 그대로 이어집니다.** (Claude 는 대화로 학습하지 않으며, 앱이 매 요청마다 시스템 프롬프트 + 장기 기억 + 요약 + 최근 대화를 보냅니다.) 목록에 없는 모델 ID 는 `settings.json` 의 `model` 에 직접 적으면 됩니다.

설정 파일 위치: `%APPDATA%\desktop-companion\settings.json` (DB 는 같은 폴더의 `companion.sqlite`)

## 기억과 백업

- **대화 기록** → 최근 N개(기본 20)는 그대로, 오래된 것은 요약으로 접어서 보냅니다.
- **장기 기억** → Claude 가 `save_memory` 도구로 직접 저장하고, 설정 화면에서 보고 삭제할 수 있습니다.
- **백업** → 설정에서 백업 폴더를 지정하면 하루 1회(앱 종료 시 포함) 스냅샷을 만들고 지정한 개수만 보관합니다. 폴더를 OneDrive/Google Drive/Dropbox 안에 두면 클라우드 백업이 됩니다.
  - 실사용 중인 DB 파일을 동기화 폴더에 직접 두지 마세요. 앱이 `VACUUM INTO` 로 만든 **스냅샷 사본**만 그곳에 둡니다.
  - 복원은 설정 → 백업에서 복원…
  - 사람이 읽는 장기 기억만 `.md` 로 내보내 깃 저장소에 올릴 수도 있습니다. 전체 대화 기록을 깃에 올리는 것은 권하지 않습니다.
- API 키는 백업/내보내기에 포함되지 않습니다.

## 컴퓨터 제어 (기본: 끔)

설정 → 컴퓨터 제어

| 모드 | 가능한 일 |
|---|---|
| 끔 | 대화와 기억 저장만 |
| 제한 | `open_url`(Edge 로 http/https 주소 열기), `open_app`(허용 목록의 앱 실행). **실행 때마다 확인 창** |
| 전체 | 준비 중 (마우스/키보드 직접 조작) |

- 앱 허용 목록은 `settings.json` 의 `apps` 에서 편집합니다. 목록 밖 프로그램은 실행할 수 없고, 셸을 거치지 않습니다.
- **화면 보기**는 별도 옵션입니다. 켜면 Claude 가 요청할 때마다 확인 창을 거쳐 선택한 모니터를 캡처해 분석합니다. 캡처된 화면은 Anthropic API 로 전송됩니다.
- 화면/웹 내용 속 지시문은 따르지 않도록 시스템 프롬프트에 규칙이 들어 있습니다.

## TTS 교체

`src/core/tts/` 에 `synthesize(text) → { data: Buffer, mime }` 만 구현하고 `index.js` 의 `PROVIDERS` 에 등록하면 설정 화면의 엔진 목록으로 쓸 수 있습니다.

- `edge.js` : Edge TTS (무료, 임시). 기본 음성 `ko-KR-SunHiNeural`
- `sbv2.js` : Style-Bert-VITS2 로컬 서버(`/voice`) 연결. **아직 실제 서버로 검증하지 못했습니다.** 학습 후 서버를 띄우고 주소·모델 ID·화자 ID·언어를 설정에 넣어 확인해 주세요. SBV2 는 공식적으로 일본어/영어/중국어 중심이라 한국어 지원 여부를 먼저 확인해야 합니다.
- 학습에 쓰는 음성은 본인 목소리이거나 이용 허락을 받은 데이터여야 합니다.

## 구조 (서버 이전을 염두에 둔 분리)

```
src/core/      두뇌 (순수 Node, Electron 비의존) ← 나중에 서버로 이전 가능
  brain.js       기억 + LLM + 도구 + 음성 파사드 (화면은 이 인터페이스만 앎)
  llm.js         스트리밍 대화 루프, 도구 사용, 롤링 요약
  tools.js       도구 레지스트리 (권한/검증/확인)
  memory.js      SQLite    backup.js   스냅샷    config.js   설정
  speech.js      문장 단위 TTS 큐    tts/   엔진들
src/main/      Electron 메인: 창, 트레이, IPC, API 키 보관, OS 기능(브라우저/앱/화면 캡처)
src/renderer/  캐릭터(three-vrm), 립싱크, 채팅/설정 UI
```

OS 에 닿는 기능은 `platform`(main.js)으로만 주입됩니다. 서버로 옮길 때는 두뇌를 서버에 두고, PC 앱이 같은 인터페이스의 원격 프록시를 쓰며, 컴퓨터 제어와 GPU TTS 는 PC 앱에서 실행하게 하면 됩니다.

## 테스트와 검증 범위

`npm test` — 네트워크/API 키 없이 두뇌 로직 검증 (기억, 백업, 설정, 감정 태그, 문장 분할, 도구 권한/검증, 대화·도구 루프, 요약).

개발 환경(리눅스 컨테이너)에서 확인한 것:
- 실제 Electron 프로세스에서 IPC → 두뇌 → **Anthropic SDK 스트리밍(가짜 서버)** → 감정/텍스트/도구 호출/오디오 전달 → DB 저장까지 end-to-end
- 샘플 VRM 렌더링, 표정, 립싱크, 캐릭터 위 마우스 판정(클릭 통과)

**아직 확인하지 못한 것 (실기에서 확인 필요):** Windows 에서의 투명 창/클릭 통과/트레이 동작, 실제 Claude API 호출, Edge TTS 의 실제 음성(네트워크 필요), Style-Bert-VITS2 서버 연동, 듀얼 모니터 배치, `microsoft-edge:` 링크로 Edge 열기.
